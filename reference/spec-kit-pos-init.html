Referência rápida · Spec Kit 1.0.6

Depois do specify init

Um mapa de pastas e do ciclo Spec-Driven Development para GitHub Copilot.

As duas pastas

.github/skills/
Interface do agente. Cada subpasta contém um SKILL.md que descreve um comando, seus pré-requisitos, artefatos e critérios de conclusão.
.specify/
Infraestrutura do método. Contém templates, scripts auxiliares, memória, workflows, configuração e manifestos de integração.

Artefatos principais

LocalFunção
.specify/memory/constitution.mdPrincípios e regras de governança do projeto.
.specify/templates/Estruturas iniciais para spec, plan, tasks, checklist e constitution.
.specify/scripts/Scripts usados para preparar contexto, localizar features e validar pré-requisitos.
.specify/workflows/Registro dos fluxos instalados, como o ciclo completo do Spec Kit.
.specify/integration.jsonIntegração ativa, versão do Spec Kit e modo usado pelo Copilot.
specs/<feature>/Artefatos de uma feature: spec.md, plan.md, tasks.md e documentos de design.

Fluxo de trabalho

  1. /speckit-constitution → princípios
  2. /speckit-specify → necessidade em spec.md
  3. /speckit-clarify → ambiguidades resolvidas
  4. /speckit-plan → desenho técnico
  5. /speckit-checklist → revisão de qualidade
  6. /speckit-tasks → tarefas ordenadas
  7. /speckit-analyze → consistência entre artefatos
  8. /speckit-implement → execução e validação
  9. /speckit-converge → lacunas restantes viram tarefas
Regra de diagnóstico

Se a dúvida é “como o agente executa este comando?”, procure em .github/skills. Se a dúvida é “quais arquivos, templates ou scripts sustentam o processo?”, procure em .specify.
