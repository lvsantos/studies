Instalação do Spec Kit

O pacote instalado é specify-cli. O comando criado é specify.

Pré-requisitos

  • Python 3.11 ou superior
  • uv (recomendado) ou pipx
  • Um agente compatível, como GitHub Copilot

Instalar o CLI

uv tool install specify-cli
specify version

Atualizar e verificar

specify self check
specify self upgrade

Aviso de PATH (VS Code via Snap): Se o specify version continuar antigo após o upgrade, insira o executável diretamente em ~/.local/bin:

UV_TOOL_BIN_DIR=$HOME/.local/bin uv tool install specify-cli --force

Inicializar um projeto

specify init meu-projeto --integration copilot
# ou, dentro de uma pasta existente:
specify init --here --integration copilot

Modelo mental: instalação coloca o executável no ambiente; inicialização cria os arquivos do Spec Kit no projeto.
