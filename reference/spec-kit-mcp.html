MCP server

Servidor experimental do Specify CLI: transporte local por stdio, com suporte atual limitado a consultar a versão.

Inicialização

specify mcp
  • O host MCP inicia o comando como subprocesso local;
  • usa stdio; não oferece HTTP, SSE, daemon ou seleção de transporte;
  • stdout é reservado para mensagens MCP, sem banner ou logs.

A configuração para iniciar subprocessos é específica de cada host. A referência do Spec Kit não define um snippet universal para clientes.

Ferramentas e escopo atual

FerramentaPropósito
specify_list_commandsLista os comandos CLI aceitos via MCP.
specify_describe_commandDescreve um comando pontuado suportado.
specify_run_commandExecuta um comando aceito pela interface MCP.

Nesta versão experimental, só version é suportado. Outros nomes retornam unavailable_command. A ferramenta de execução chama specify version --json em um processo filho isolado, no mesmo ambiente Python do CLI.

Resultados e erros

  • Sucesso: objeto JSON direto com cli_version, runtime, system e features, sem envelope universal;
  • falha do CLI: erro MCP com error.code, error.message e error.details;
  • saída vazia, inválida ou não JSON: adapter_internal_error sanitizado.

Fora do escopo

O servidor não expõe descoberta de projetos, artefatos, mutações, instalação ou atualização, workflows, confirmações ou níveis de acesso. Não confunda o servidor MCP com a integração do agente; specify init --integration ... continua sendo uma configuração separada.

Aviso: a superfície MCP é experimental. Ferramentas e contratos podem mudar.
