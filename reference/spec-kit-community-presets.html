Presets comunitários

Pesquise no catálogo, confira o pacote na origem e valide o efeito depois da instalação. A presença no catálogo não é auditoria nem endosso.

Fluxo de descoberta

specify preset catalog list
specify preset search [query]
specify preset search --tag <tag>
specify preset search --author <author>
specify preset info <preset-id>

O fluxo requer um projeto inicializado. A busca consulta os catálogos ativos; use catalog list para conferir nomes, prioridades e permissão de instalação.

Revisão antes de instalar

  • Leia propósito, README e requisitos de versão/extensões.
  • Confira autor, repositório, licença, release e histórico.
  • Conte e inspecione templates, comandos e scripts que o preset fornece.
  • Compare o pacote com a origem da versão indicada; valide o SHA-256 quando disponível.
  • Teste em branch ou projeto descartável e revise o diff.

Os mantenedores verificam completude e formato dos metadados no catálogo, não o código do preset.

Instalação e verificação

specify preset add <preset-id>
specify preset list
specify preset resolve <nome-do-arquivo-ou-comando>
specify preset remove <preset-id>

Exemplo do catálogo: vscode-ask-questions afeta o comando de esclarecimento para VS Code. Confirme seu conteúdo no repositório antes de instalar. Para remover arquivos e comandos registrados, use remove; disable não retira os comandos já registrados no agente.

First-party/bundled

  • lean: comandos de workflow mais minimalistas.
  • constitution-sync: propagação opt-in da constituição para artefatos materializados, com implicações de drift.

Lista oficial: presets/catalog.json. Lista comunitária: presets/catalog.community.json.
