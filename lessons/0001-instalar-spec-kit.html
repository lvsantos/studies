Instalar o Spec Kit sem misturar as duas etapas

Vitória de hoje: deixar o comando specify disponível e saber quando inicializar um projeto.

A ideia central

Spec Kit tem dois momentos diferentes:

  1. Instalar o CLI: instala o pacote specify-cli uma vez no seu ambiente.
  2. Inicializar um projeto: usa specify init para criar a estrutura e a integração do agente naquele projeto.

1. Instale e verifique

Com Python 3.11+ e uv disponíveis:

uv tool install specify-cli
specify version

Se o segundo comando mostrar uma versão, a instalação do CLI terminou. A documentação oficial também descreve pipx install specify-cli como alternativa.

Se aparecer “Executable already exists: specify”

Esse aviso significa que já existe um executável specify no seu ambiente. Não é necessário reinstalar para continuar: execute:

specify version

Se o comando mostrar o quadro Specify CLI Information e uma versão, o CLI já está instalado e funcionando. Só use --force se você realmente quiser substituir a instalação existente.

Como saber se está atualizado

specify version mostra apenas a versão instalada. Para consultar se existe uma versão mais nova, use o comando somente leitura:

specify self check

O resultado informa Up to date quando não há atualização ou mostra algo como Update available: versão-atual → versão-nova quando há uma versão disponível.

Para visualizar o plano de atualização sem alterar nada:

specify self upgrade --dry-run

Para instalar a versão estável mais recente:

specify self upgrade

Depois, confirme novamente com specify version. O comando self upgrade identifica se a instalação foi feita com uv ou pipx.

Solução de problemas: “Verification failed” ou PATH incorreto (VS Code Snap)

Se após o specify self upgrade você receber o aviso de que o diretório não está no PATH (ex: ~/snap/code/.../.local/bin) e a versão continuar antiga no terminal, isso ocorre porque o VS Code rodando via Snap instala os binários no diretório de sandbox do Snap, enquanto seu terminal prioriza ~/.local/bin.

Para resolver e forçar a instalação no diretório padrão do usuário (~/.local/bin):

UV_TOOL_BIN_DIR=$HOME/.local/bin uv tool install specify-cli --force --from git+https://github.com/github/spec-kit.git@v1.0.6

Ou para versões estáveis do PyPI:

UV_TOOL_BIN_DIR=$HOME/.local/bin uv tool install specify-cli --force

Em seguida, execute specify version para confirmar a versão atualizada.

2. Inicialize para o Copilot

Para criar um novo diretório:

specify init meu-projeto --integration copilot

Para usar a pasta atual:

specify init --here --integration copilot

Em uma pasta existente e não vazia, use --force somente depois de conferir o que será mesclado.

Recuperação antes de executar

Sem olhar acima: qual comando instala o CLI? E qual comando prepara um projeto para o Copilot?

Instalação: uv tool install specify-cli

Projeto: specify init meu-projeto --integration copilot

Seu próximo passo

  1. Execute a instalação e confirme com specify version.
  2. Escolha uma pasta de teste e execute o specify init.
  3. Observe quais arquivos o comando criou antes de começar a primeira especificação.
